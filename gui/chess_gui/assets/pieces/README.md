# Pièces d’échecs Cburnett

Ces images PNG sont des rendus des pièces SVG créées par Cburnett et
distribuées par Wikimedia Commons. Elles sont embarquées afin que l’interface
reste identique sur Windows, Linux et macOS, sans dépendre d’une police
Unicode installée localement.

Sources :

- https://commons.wikimedia.org/wiki/Template:SVG_chess_pieces
- fichiers `Chess_[kqrbnp][ld]t45.svg`
